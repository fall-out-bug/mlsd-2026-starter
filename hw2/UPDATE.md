# Как добавить HW2 в свой репозиторий

Скопируйте из стартера `check.sh`, `hw1/` и `hw2/`. Сохраните код HW1, корневой Dockerfile, зависимости и свой README. Если папка `hw2/` уже есть, сохраните свою работу перед обновлением. В стартере находятся только условия, данные и локальная проверка; файлы реализации создайте самостоятельно.

В корневой README добавьте описание HW2 и ссылки на условия [HW1](../hw1/README.md) и [HW2](README.md). Повторно регистрировать репозиторий не нужно.

Локальная проверка из корня: `sh check.sh HW1` или `sh check.sh HW2`.
