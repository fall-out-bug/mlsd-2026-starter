# Как добавить HW2 в свой репозиторий

Продолжайте работу в зарегистрированном репозитории HW1. Перенесите из стартера папки `hw1/` с условием первой работы и `hw2/` с условием и заготовкой второй.

Сохраните свою реализацию HW1 и корневой README. Добавьте в README описание проекта HW2 и ссылки на условия обеих работ. Переносить код HW1 в папку `hw1/` не нужно. Повторно регистрировать репозиторий тоже не нужно.

Если вы уже писали расчёт `customer_features(rows)` для прежней заготовки, его можно использовать в своей Spark-программе. В текущем задании нужно самостоятельно собрать весь проект: Compose, образы, DAG, Spark-кластер и сохранение результата. Прежняя заготовка с готовой инфраструктурой этому условию не соответствует.

Далее следуйте [условию HW2](README.md). Логи, результаты расчёта, содержимое volumes и личные настройки `.env` в репозиторий не включайте.
