# Добавить новую HW2 в зарегистрированный репозиторий

Скопируйте `hw2/` из опубликованной версии шаблона в существующий проект.
Сохраните свою реализацию HW1 и корневой README; дополните README описанием HW2.
Новый репозиторий регистрировать не нужно.

Если вы начинали вариант с `customer_features(rows)` в готовом пайплайне,
сохраните свой код перед обновлением: расчёт можно использовать в собственной
Spark-программе. Старая Compose-конфигурация и готовый DAG не выполняют новый
контракт полного проекта. Новую версию задания преподаватель объявит отдельно.

Готовые результаты, логи и `.env` не коммитьте. Отправляйте весь проект и README
одним коммитом с последней строкой `MLSD-HW: HW2` после открытия задания.
