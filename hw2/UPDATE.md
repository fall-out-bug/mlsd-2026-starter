# Добавить HW2 в существующий репозиторий

Работайте в том же зарегистрированном репозитории и ветке `main`, где сдавали HW1. Создавать новый репозиторий и повторно регистрироваться не нужно. Корневой Dockerfile, сервис и результат HW1 сохраняются.

Эти команды нужны **после объявления выпуска 5 октября после лекции 3**, когда `hw2/` появится в основной ветке шаблона. Перед началом сохраните текущую работу коммитом; `git status --short` должен быть пустым. Команды ниже предназначены для первого добавления: если у вас уже есть собственная папка `hw2/`, сначала сохраните её содержимое и переносите обновления отдельно.

Из корня своего репозитория:

```sh
git remote add course-template https://github.com/fall-out-bug/mlsd-2026-starter.git
git fetch course-template main
git restore --source=course-template/main -- hw2
git add hw2
git commit -m 'Добавить заготовку HW2'
```

Если remote `course-template` уже добавлен с этим адресом, повторно добавлять его не надо. Шаблон GitHub может иметь другую историю коммитов; здесь переносится только папка `hw2/`, поэтому объединять истории репозиториев не требуется. Этот технический коммит ещё не сдача.

Далее откройте [условие](README.md), реализуйте `customer_features.py`, выполните `sh hw2/check.sh` и сдайте отдельным коммитом `MLSD-HW: HW2`, как описано в условии. Корневой `sh check.sh` относится к HW1.
