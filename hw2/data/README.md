# Online Retail II — учебная выборка

`sample.csv` содержит 11 116 товарных строк, около 1 МБ. Используйте этот файл для HW2; полный датасет скачивать не нужно. Полный исходный архив хранится у преподавателя.

## Формат данных

CSV в кодировке UTF-8 содержит восемь колонок:

| Поле | Значение |
|---|---|
| `invoice_id` | Номер заказа; префикс `C` обозначает отмену |
| `stock_code` | Код товара |
| `description` | Описание товара; может отсутствовать |
| `quantity` | Количество единиц товара, целое число со знаком |
| `invoice_at` | Время заказа в формате ISO 8601 без часового пояса |
| `unit_price` | Цена единицы товара, до шести знаков после запятой |
| `customer_id` | Идентификатор клиента; может отсутствовать |
| `country` | Страна |

Выборка сохраняет все товарные строки отобранных заказов, включая отмены, возвраты и пропуски. Правила отбора строк для расчёта признаков описаны в [условии HW2](../README.md).

`SHA256SUMS` содержит контрольную сумму `sample.csv`. На этапе `get_dataset` ваша программа должна проверить, что входной файл ей соответствует. Это проверка целостности предоставленного файла; очищать и отбирать данные нужно в Spark-программе, сохраняя исходный CSV.

## Источник и ограничения

Chen, D. (2012). *Online Retail II*. UCI Machine Learning Repository. DOI: [10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D). [Страница датасета](https://archive.ics.uci.edu/dataset/502/online%2Bretail%2Bii). Лицензия — CC BY 4.0.

Это учебная выборка заказов, а не полная история клиентов и не статистически репрезентативная выборка рынка. Данные исторические; они сохраняют пропуски, отмены, возвраты и ошибки исходного набора. Часовой пояс исходных дат не указан.
