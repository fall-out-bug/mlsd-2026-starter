# Online Retail II

`sample.csv` — малый файл для разработки и локальной проверки: 11 116 товарных строк, около 1 МБ. Выбраны заказы целиком, включая отмены и возвраты.

CSV записан в UTF-8. Поля и правила обработки приведены в [условии HW2](../README.md#данные). `invoice_at` содержит время в формате ISO 8601 без часового пояса; `unit_price` — десятичное число, до шести знаков после запятой. Идентификаторы клиентов могут отсутствовать.

На сервере проверяется полный файл с теми же колонками. Результат малого файла описывает только покупки в этой выборке.

Источник: Chen, D. (2012). [Online Retail II](https://archive.ics.uci.edu/dataset/502/online%2Bretail%2Bii), UCI Machine Learning Repository. DOI: [10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D). Лицензия — CC BY 4.0.
