# Подключение репозитория к системе курса

После локального `PASS` по `sh ./check.sh` выполните один раз:

1. Откройте **https://mlsd.beetles.family** и войдите через GitHub.
2. Система попросит установить GitHub App курса — подтвердите установку
   для вашего приватного репозитория с HW1.
3. Выберите ваш репозиторий из списка.
4. Привяжите Telegram: бот курса пришлёт ссылку в чат — откройте её.

После привязки каждый push в `main` с коммитом-маркером `MLSD-HW: HW1`
автоматически ставится в очередь на серверную проверку. Результаты приходят
в Telegram и появляются на коммите (GitHub Checks).

Локальный `PASS` — только самопроверка; приём работы фиксирует сервер.
