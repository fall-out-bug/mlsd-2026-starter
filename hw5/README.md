# Домашняя работа 5. Поток транзакций и мониторинг данных

HW5 продолжает HW4 — тот же проект на Online Retail II, поток транзакций и
мониторинг данных. Можно опереться на своё решение HW4 или написать весь код
заново: контракт фиксирует наблюдаемое поведение и артефакты, а не способ
реализации. Модели предоставлены в `models/`; обучение и выпуск новых версий
не запускаются.

Полное условие — [TECHNICAL.md](TECHNICAL.md): сервисы, поток, учебное время,
признаки, прогнозы, восстановление, мониторинг, зрелые метки, ошибки и
лимиты.

## Что нужно построить

- `hw5/compose.yaml` с обязательными сервисами (§2), включая `stream-worker`
  и `monitor`.
- `stream-worker` — приём транзакций и заданий из Redis Streams
  (`hw5:events`, `hw5:requests`), состояние клиентов, признаки, неизменяемые
  прогнозы, точки паузы и восстановление.
- `monitor` — качество входов, сдвиг, здоровье потока, зрелые метки и
  качество по сохранённым прогнозам, алерты с подтверждением.
- `gateway` — публичный вход, включая `GET /predictions/{request_id}`.
- `runbook.md` с разделами «Алерты», «Реакция», «Эскалация».
- `requirements.lock` и `README.md` с запуском и переменными окружения.

Структура каталогов и модулей — на ваше усмотрение; контракт фиксирует
наблюдаемое поведение и артефакты.

## Данные и сценарии

В `hw5/data/` — 14 открытых сценариев всех классов (`scenarios/`),
независимые ожидания (`expected.json`) и рабочая тетрадь
[SCENARIOS.md](data/SCENARIOS.md): исходное состояние, команды, ожидаемые
наблюдения и действия при расхождении. Прочитайте сценарий и предскажите
результат до запуска. Модели-фикстуры — в `hw5/models/`, toy-вход — в
`hw5/input/`.

## Запуск

```bash
cd hw5
docker compose up --build --wait
```

Вход монтируется read-only в `/input` через `HW5_INPUT_DIR`. `feature-build`
и `feature-loader` — одноразовые сервисы; `gateway` стартует после их
успешного завершения.

## Проверка и сдача

```bash
sh check.sh HW5
```

Локальный PASS не заменяет серверный зачёт. Сдача — ветка `main`, последняя
строка сообщения коммита — ровно `MLSD-HW: HW5`.

HW5 выдаётся 23 ноября 2026 в 21:00 МСК. Ранний бонус +3 — строго до
30 ноября 18:00 МСК. Мягкий дедлайн — 7 декабря 18:00 (10 базовых баллов,
далее −1 за каждые полные 24 часа), жёсткий — 14 декабря 18:00 (ноль).
OpenSpec-бонус +2 подключается до 24 ноября 21:00; до подключения сдача
принимается без него.
