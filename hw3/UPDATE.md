# Как добавить HW3 в репозиторий HW1/HW2

HW3 продолжает ваш существующий проект: окружение HW2 (compose, Dockerfile'ы,
Airflow, Spark, SeaweedFS) остаётся основой. Скопируйте каталог `hw3/`
и обновлённый `check.sh` из starter. Сохраните свои `hw1/`, `hw2/`, корневой
Dockerfile, зависимости и README.

Что делаете сами, по контракту из [TECHNICAL.md](TECHNICAL.md):

1. Добавьте сервис `mlflow` в ваш compose (раздел 2) и при необходимости
   доработайте Dockerfile(ы).
2. Создайте DAG `online_retail_training` с обязательными задачами
   `stage_input → build_examples → train_select → evaluate → publish`.
3. Напишите код решения: окна, разметка, Spark-агрегаты, обучение,
   сравнение кандидатов, bundle, оценка. Структура каталогов — ваша;
   контракт описывает входы/выходы стадий (раздел 4) и схемы артефактов.
4. Объявите `config/candidates.json` и зафиксируйте `requirements.lock`.

Добавьте в корневой README ссылку на HW3. Проверьте прежние работы командами
`sh check.sh HW1` и `sh check.sh HW2`, затем запустите `sh check.sh HW3`.
Стартер не содержит проекта HW3: несобранный проект получает учебный отказ
`compose_missing`, пустые стадии DAG — `FAILED`. Сроки HW3: до 2 ноября
18:00 МСК действует ранняя сдача (10 базовых баллов и 3 за раннюю сдачу),
мягкий дедлайн 9 ноября 18:00 МСК, жёсткий дедлайн 16 ноября 18:00 МСК.
