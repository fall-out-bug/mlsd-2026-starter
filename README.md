# MLSD 2026 — репозиторий учебного проекта

Этот шаблон используется для одного проекта на весь курс. Каждая домашняя
работа добавляет возможности в тот же зарегистрированный репозиторий;
создавать новый репозиторий для HW2 не нужно.

| Работа | Условие | Локальная проверка из корня | Маркер сдачи |
|---|---|---|---|
| HW1: сервис в Docker | [Инструкция HW1](hw1/README.md) | `sh ./check.sh` | `MLSD-HW: HW1` |
| HW2: данные и агрегаты по клиенту | [Инструкция HW2](hw2/README.md) | `sh hw2/check.sh` | `MLSD-HW: HW2` |

В `hw1/` лежит только инструкция. Сервис HW1, его `Dockerfile`, файл
зависимостей и команды сборки остаются в корне репозитория. Файлы HW2
лежат в `hw2/`; добавление HW2 не требует переноса или удаления HW1.

Если вы уже сдавали HW1, используйте [инструкцию обновления](hw2/UPDATE.md).
Обе работы сдаются в ветке `main` через систему курса. Локальный `PASS`
подтверждает только локальную проверку; приём работы и оценку подтверждает
серверный результат. Следующее задание открывается после объявления
преподавателем; наличие заготовки в шаблоне само по себе не открывает приём.

Шаги развития проекта описывайте пакетами OpenSpec в
`openspec/changes/<имя-изменения>/`. Состав пакета и условия бонуса приведены
в инструкции каждой работы. Для повторной сдачи используйте новый коммит
с маркером нужной работы.
