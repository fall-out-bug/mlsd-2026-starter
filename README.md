# MLSD 2026 — учебный проект

Все домашние работы выполняются в одном зарегистрированном репозитории.

| Работа | Условие | Проверка | Маркер коммита |
|---|---|---|---|
| HW1: сервис в Docker | [HW1](hw1/README.md) | `sh check.sh` | `MLSD-HW: HW1` |
| HW2: полный проект данных и признаков | [HW2](hw2/README.md) | `python3 hw2/check.py` | `MLSD-HW: HW2` |

HW1 и её файлы остаются в корне; HW2 находится в `hw2/`.
Локальный PASS подтверждает локальную проверку,
приём и оценку подтверждает серверный результат.
