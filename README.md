# MLSD 2026 — учебный проект

Все домашние работы выполняются в одном зарегистрированном репозитории.

| Работа | Условие | Локальная проверка из корня | Маркер сдачи |
|---|---|---|---|
| HW1: сервис в Docker | [Условие HW1](hw1/README.md) | `sh check.sh` | `MLSD-HW: HW1` |
| HW2: проект подготовки клиентских признаков | [Условие HW2](hw2/README.md) | `python3 hw2/check.py` | `MLSD-HW: HW2` |

В этом README собраны ссылки на задания. Условия HW1 находятся в `hw1/README.md`, а код HW1 и его Dockerfile остаются в корне. Условие и файлы HW2 находятся в `hw2/`. Для существующего репозитория есть [инструкция обновления](hw2/UPDATE.md).

Код каждой работы нужно сдать обязательно. OpenSpec — необязательная работа на бонус: пакет можно отправить сразу или отдельно. Его проверка начинается после успешного зачёта кода. Если код уже зачтён, повторно сдавать его не нужно.

Работы сдаются в ветке `main`. Результаты серверной проверки приходят в Telegram и появляются на коммите в GitHub. Локальный `PASS` подтверждает проверку на вашей машине; оценку выставляет сервер курса.
